# برنامه اندروید «قرآن و اوقات شرعی»

این پروژه همان سایت (فایل `app/src/main/assets/index.html`) را **بدون هیچ تغییری** داخل یک WebView اندروید اجرا می‌کند؛
پس متن عربی ۱۱۴ سوره، ساختار صفحه‌ها (قرآن، اوقات شرعی، ذکرشمار)، ابجد، تقویم شمسی و ساعات نجومی دقیقاً مثل سایت است.

## ساخت APK

### روش ۱: Android Studio
1. Android Studio (نسخه‌ی جدید) را نصب کنید.
2. `File > Open` و پوشه‌ی `QuranApp` را انتخاب کنید و صبر کنید Gradle Sync تمام شود.
3. برای نسخه‌ی تست: `Build > Build APK(s)`؛ خروجی در `app/build/outputs/apk/debug/app-debug.apk`.
4. برای انتشار: `Build > Generate Signed Bundle / APK`.

### روش ۲: بدون Android Studio (GitHub Actions)
پروژه را در یک مخزن GitHub بریزید. workflow آماده در `.github/workflows/build.yml` است؛
بعد از push، از تب Actions فایل `QuranApp-debug-apk` را دانلود کنید.

## اضافه‌شده‌ها نسبت به سایت
- نمایش درست `alert` و `confirm` سایت (در WebView به‌صورت پیش‌فرض نمایش داده نمی‌شوند).
- دسترسی به GPS برای دکمه‌ی موقعیت‌یاب (درخواست مجوز از کاربر).
- اعلان اذان: چون WebView از `Notification` پشتیبانی نمی‌کند، به اعلان واقعی اندروید وصل شده است.
- فونت‌های Vazirmatn و Scheherazade New داخل برنامه هستند (متن قرآن آفلاین هم درست نمایش داده می‌شود).
- دکمه‌ی برگشت: بستن تقویم ← بازگشت به تب قرآن ← خروج.

## نیاز به اینترنت
- **آفلاین کار می‌کند:** متن عربی قرآن، ابجد، ذکرشمار، تقویم، تم، نشانه‌ی ختم.
- **اینترنت می‌خواهد:** ترجمه‌ها (api.alquran.cloud)، تفسیر (alvahy.com)، اوقات شرعی (api.aladhan.com)،
  جستجوی شهر، نام شهر از GPS و تصاویر پس‌زمینه‌ی هدرها.

## نکته
مثل خود سایت، اذان فقط وقتی برنامه باز/در حال اجراست اعلان می‌دهد. اذان پس‌زمینه (حتی با بسته بودن برنامه)
نیاز به نوشتن بخش بومی با AlarmManager دارد که جزو سایت اصلی نبود.

## به‌روزرسانی محتوا
هر تغییری در سایت: فقط `app/src/main/assets/index.html` را جایگزین و `versionCode` را در `app/build.gradle.kts` زیاد کنید.
